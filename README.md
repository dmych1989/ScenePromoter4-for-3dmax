# 场景助手 4（ScenePromoter4）

一个面向 **3ds Max** 的 MAXScript 插件，提供可停靠的侧边面板与工具栏，把常用的建模/材质/场景整理脚本集中管理，并支持自定义配色、个性化标题栏、多版本数据同步等。

> 原始版本历史：场景助手 1.0（2008）→ 2.0 → 3.0 → 4.0（2011）→ 4.1（2012）→ 4.2。
> 本仓库在原插件内核基础上，附带**新版安装包生成工具**——基于 NSIS 向导式安装包（与原版同款），将插件解压到本地所选目录，不自动写入 3ds Max 安装目录。

---

## 功能特性

### 1. 主界面与场景信息（第一屏）
打开 3ds Max 后自动出现的侧边面板，第一屏实时统计当前场景：
- 总面数 / 选择面数、所有物体数 / 选择物体数
- 没有材质的物体数量
- 所有材质 / 选择物体材质 / 同名材质 / 材质库 数量
- **丢失贴图**数量、各类材质类型分布
- 一键操作：选择无材质物体、导入所有/选择/同名/材质库/丢失的材质、按材质类型批量导入

### 2. 脚本库（第二～五屏 + 助手工具栏）
- 二~五屏与「助手工具栏」是一组**可自定义的脚本收藏夹**，点击即用。
- 脚本来源为 `Lib/` 目录下的 `.ms` / `.mse` 文件，也支持把 `.exe` 加为快捷启动。
- 自带数十个常用脚本（VRay 相关、超级分离、按元素分离、CAD 相关、材质库整理等，见 `Lib/`）。

### 3. 脚本管理
通过「选项 → 脚本管理」统一维护：
- 添加单个脚本 / 整个文件夹 / exe / 空行 / 新建脚本
- 重命名、编辑源码、删除脚本（同时清理对应按钮）
- 上移 / 下移排序、清除失效空按钮
- 「无家可归」视图：列出 `Lib/` 下尚未加入面板的脚本，一键收录

### 4. 界面自定义
- **主界面设置**：面板高度/宽度、是否随 Max 自动启动、悬浮/停靠（左/右）切换、面板收缩
- **配色方案**：导航背景、面板背景、链接色、文本色四色可调，支持保存 / 重命名 / 删除多套自定义方案
- **工具栏设置**：按钮长/宽像素偏移

### 5. 个性化 3ds Max
「选项 → 个性化 Max」可：
- 自定义标题栏内容：文件名、路径、大小、创建时间、修改时间、Max 版本（打开/保存/新建/重置后自动刷新）
- 显示或隐藏：时间滑块、动画帧轨道、状态栏、修改面板
- 切换「按名称选择」使用场景浏览器（旧/新样式）、材质编辑器样式

### 6. 数据同步（多 Max 版本共用）
「选项 → 数据同步」：把当前 Max 下的场景助手（脚本 + 配置）一键同步到本机其它 3ds Max 安装目录，实现多版本**免重复安装、配置完全一致**。

### 7. 快捷方式
为任意脚本生成 MAXScript 宏命令快捷方式，出现在
`自定义 → 自定义用户界面 → 类别：FeilangTools` 下，可自由绑定到菜单/工具栏/快捷键；并在「选项 → 快捷方式」中集中管理、删除。

### 8. 其它
- 重启 Max、内置使用说明与详细帮助（`Help/`）、关于面板
- 「选项 → 卸载」可清理插件
- 启动时强制 `zh-cn` 区域设置，避免中文乱码

## 支持的 3ds Max 版本

- 依据原始说明，适配 **3ds Max 9 / 2009–2014（32 位与 64 位）**。
- 源码通过 `maxversion()` 做版本判断，理论上可向上兼容更多版本，但未经全部新版本逐一测试；如遇不兼容可在 Issue 反馈。

## 安装

### 方式一：安装包（本地解包，无需管理员）
1. 运行配套安装包（见下方「重新生成安装包」），双击即可（不需要管理员权限）。
2. 向导让你**选择安装目录**（默认 = 安装包所在目录），确认后把插件解压到该目录下的 `Scripts\` 文件夹中：
   - `Scripts\ScenePromoter4\` —— 主脚本 + `Lib/` + `Help/` + `images/`
   - `Scripts\Startup\SP4_startup.ms` —— 启动脚本
3. 把解压出的 `Scripts` 目录接入 3ds Max 的脚本路径（自定义 → 配置系统路径 → 文件 → 添加 `Scripts` 目录），或直接把 `Scripts\ScenePromoter4\` 与 `Scripts\Startup\` 复制到 `<Max安装目录>\scripts\` 下。
4. **重启 3ds Max** 即可，启动时会自动加载面板。

### 方式二：手动安装
1. 把本仓库 `ScenePromoter4/` 整个目录复制到 ` <Max安装目录>\scripts\ ` 下，即得到 `<Max>\scripts\ScenePromoter4\`。
2. 把 `SP4_startup.ms` 复制到 `<Max>\scripts\Startup\`。
3. 重启 3ds Max。`SP4_startup.ms` 会在启动时依次 `filein` 各主脚本并自动打开面板（可在「界面设置」里关闭自动启动）。

## 目录结构

```
ScenePromoter4/
├─ SP4_startup.ms          # 启动脚本：放入 scripts\Startup\，随 Max 自启
├─ ScenePromoter.ms        # 宏命令入口（FeilangTools 类别）
├─ ScenePromotermcr.ms     # 菜单 / 各类设置对话框定义
├─ SPMainRollout.ms        # 主面板（TreeView + 多屏导航 + 场景信息）
├─ CGplusplusFunc.ms       # 核心工具函数库
├─ ScenePromoter4.ini      # 配置文件（面板尺寸/配色/停靠等）
├─ Lib/                    # 内置脚本库（.ms/.mse，可自定义扩充）
├─ Help/                   # 使用说明与帮助文档
├─ images/                 # 界面图标与 Logo
├─ build.ps1              # 原 .NET 方案安装包构建脚本（参考）
├─ installer.nsi          # 安装包脚本（NSIS，向导式，与原版 4.1.1 同款；本地解包，不自动写入 Max 目录）
└─ build_nsis.bat         # 编译安装包的批处理（需先安装 NSIS）
```

> 说明：仓库刻意**不包含任何编译产物（`.exe` / `dist/` / `payload.zip` 等）**，保持源码纯净；安装包由下面的脚本在本地生成。

## 重新生成安装包（开发者）

本安装包使用 **NSIS（Nullsoft 安装系统）** 制作，与原版 `场景助手4_1_1.exe` 同款——向导式安装（欢迎 → 选择安装目录 → 安装 → 完成），并自动在控制面板注册卸载项，**不是自解压包**。

环境要求：安装 NSIS（https://nsis.sourceforge.io ，安装时会自动加入 PATH）。

```bat
REM 方式一：直接运行批处理
build_nsis.bat

REM 方式二：手动调用 makensis
makensis installer.nsi
```

生成的 `dist\场景助手4_3_0.exe` 即为安装程序：
- 向导式界面，让你选择安装目录（默认 = 安装包所在目录），把插件解压到该目录下的 `Scripts\` 中
- 解压内容：`Scripts\ScenePromoter4\`（主脚本 + Lib/Help/images）与 `Scripts\Startup\SP4_startup.ms`；再由用户自行接入 3ds Max

## 卸载

若通过安装包安装，也可在 Windows 控制面板「程序和功能」中卸载（会清空所选安装目录下的 `Scripts\` 并移除卸载程序）。

在插件「选项 → 卸载」中执行清理；或手动删除：
- `<Max>\scripts\ScenePromoter4\` 目录
- `<Max>\scripts\Startup\SP4_startup.ms`
- `<Max>\ui\macroscripts\FeilangTools-SP_*.mcr`（生成的快捷方式，如有）
